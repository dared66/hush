# Hush artwork

Original MIT-licensed artwork: a mint H joined by a soft wave on a dark teal tile. `Hush.png` is the 1024-pixel master; `Hush.icns` contains standard and Retina sizes for the app and audio device.

Regenerate on macOS with `zsh scripts/build-icons.sh`. Editable source is in `scripts/render-icons.swift`; no image-generation service is needed.
